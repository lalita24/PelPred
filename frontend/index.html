📌 เมนู

  • คู่มือแนะนำการใช้งาน
  • กระบวนการจำแนกเพศ

ระบบจำแนกเพศจากโครงกระดูกส่วนสะโพก
ด้วยเทคนิคการประมวลผลภาพ

ℹ️ รายละเอียด:
ระบบนี้วิเคราะห์ และจำแนกเพศของโครงกระดูกโดยใช้เทคนิคการประมวลผลภาพ (Image Processing) ร่วมกับ Deep Learning เพื่อจำแนกเพศจากภาพถ่ายโครงกระดูกส่วนสะโพก ปัจจุบันโมเดลมีความแม่นยำในการทดสอบอยู่ที่ประมาณ XX%
แต่อย่างไรก็ตาม ระบบจำแนกเพศอาจมีข้อจำกัดในบางกรณี และควรวิเคราะห์ร่วมกับการประเมินผลโดยผู้เชี่ยวชาญ

📖 คู่มือแนะนำการใช้งาน

เพื่อให้ได้ผลลัพธ์ที่แม่นยำที่สุด กรุณาเตรียมรูปภาพตามคำแนะนำด้านล่างนี้

✅ ตัวอย่างภาพที่ทำนายแล้วมีประสิทธิภาพดีที่สุด

  • 1. ภาพกระดูกด้านหน้า
  • 2. กระดูกวางตรง ไม่เอียง
  • 3. พื้นหลังเรียบ สีเข้ม
  • 4. ไม่มีสิ่งรบกวน

❌ ตัวอย่างภาพที่ผลการทำนายมีประสิทธิภาพลดลง

  • 1. วางกระดูกเอียง
  • 2. พื้นหลังขรุขระ สีโทนสว่าง
  • 3. มีสิ่งรบกวน
  • 4. ภาพไม่ชัด

เริ่มทำการวิเคราะห์

คำแนะนำ: ควรใช้ภาพกระดูกด้านหน้า วางตรง พื้นหลังเรียบสีเข้ม และไม่มีสิ่งรบกวน
